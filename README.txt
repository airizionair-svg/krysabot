PetriDish Online Checker - read-only мониторинг для Windows

Что делает
- Раз в минуту читает публичный список серверов с https://petridish.pw/en/
- Сравнивает онлайн на каждом сервере с предыдущим замером.
- Если игроков стало на 5+ больше, шлёт уведомление в Telegram.
- Не входит в аккаунт и не управляет игрой.

Запуск
1. В @BotFather выполни /revoke для бота, получи НОВЫЙ токен (старый был засвечен).
2. Открой config.json, вставь новый токен в bot_token.
3. Проверь chat_id. У групп/каналов он начинается с -100.
   Если не уверен: отправь в группе /start@ИмяБота и запусти в этой папке:
       py checker.py --discover-chat
   Скопируй нужный chat_id в config.json.
4. Запусти Run-PetriDishOnlineChecker.cmd

Первый запуск только сохраняет baseline (state.json), уведомлений не будет.
Дальше сравнение идёт с предыдущей проверкой.

Про SSL
Скрипт использует сертификаты из хранилища Windows. Если сертификат сайта всё равно
не проходит проверку (антивирус/прокси/VPN), страница читается без проверки
сертификата - это только публичные данные. Telegram всегда проверяется полностью.

Настройки (config.json)
- poll_seconds: интервал, минимум 60
- increase_by: порог прироста игроков

Не публикуй config.json: в нём токен.

Ошибка SSL при отправке в Telegram
Если в логе "Ошибка соединения с Telegram ... self-signed certificate", HTTPS-трафик к
Telegram подменяет антивирус, прокси или VPN. Лучше всего отключить в антивирусе проверку
HTTPS/сканирование защищённых соединений (или добавить исключение для api.telegram.org),
либо выключить VPN. Если это невозможно, в config.json поставь "telegram_verify_ssl": false
(токен бота тогда не защищён от перехвата в этой сети).
